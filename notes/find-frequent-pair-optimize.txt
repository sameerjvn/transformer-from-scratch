Ohh, Now we have a new edge case: A new pair ("th", "th") has occured. But then to catch this while counting, we should have already merged. However, that's not fast enough. So let's see how we can count it before merge.

Ugh. So I guess the algorithm should be updated like this:

After each round: 
1. The pair being merged becomes of 0 frequency in the byte_pair_freqs. That pair will definitely disappear. 
2. To find the newly appeared pairs and affected pairs, we can loop through the (old) pretokens_to_counts, check if the merged pair, eg: ("t", "h") exists in each of the pretokens. (I'm assuming this check will be done by python standard lib using "in" operator, which loops through the pretoken super fast and is negligible. fingers crossed). if it exists, loop through pairs in the pretoken:
    2.1 if the current pair doesn't share any bytes with the merged pair, eg: ("p", "a"), skip the pair.
    2.2 if the current pair does share any bytes with the merged pair, eg: ("a", "t") / ("h", "t"), define two more pairs:
        2.2.1 left pair: left neighbour + first byte of current pair, eg: ("p", "a") / ("t", "h")
        2.2.2 right pair: second byte of current pair + right neighbour eg: ("t", "h") / ("t", "h")

So the update logic always stays the same. the only thing that changes is how the increasing_pair is selected. And the logic for that is as follows:

if current_pair doesn't share any bytes with the merged pair, don't update anything
else, keep going

decreasing_pair, increasing_pair = None, None
right_increasing_byte, left_increasing_byte = None, None

if left_pair == merged_pair:                            
    decreasing_pair = current_pair
    left_increasing_byte = merge_bytes(left_pair)       
elif left_pair == None:
    left_increasing_byte = first byte of current_pair   

if right_pair == merged_pair:                           
    decreasing_pair = current_pair
    right_increasing_byte = merge_bytes(right_pair)     
elif right_pair == None:
    right_increasing_byte = second byte of current_pair   

increasing_pair = left_increasing_byte + right_increasing_byte
